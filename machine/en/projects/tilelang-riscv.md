Overview

## Bring a familiar tile-level programming model to RISC-V AME CPU targets.

This project is developing a TileLang backend for RISC-V AME AI CPUs, in collaboration with the Beijing Institute of Open Source Chip and the Institute of Software, Chinese Academy of Sciences. Current work focuses on connecting the programming model to target instructions and establishing a usable compilation and execution path.

## Current work

01

### Programming model

Express common AI operators with tile-level programs and identify the information the backend needs.

02

### Target integration

Connect compiler lowering, AME instruction mapping, and the execution environment.

03

### Evaluation

Test operator correctness and performance across target configurations, and use the results to guide backend optimization.
