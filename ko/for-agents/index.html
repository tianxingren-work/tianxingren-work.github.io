TileLang-TPU

프로젝트 책임자

Python으로 고성능 커널을 작성할 수 있는 SOPHGO TPU용 TileLang 컴파일러 백엔드입니다.

TileLang-TPU는 Python으로 SOPHGO TPU에서 실행할 고성능 커널을 작성할 수 있도록 합니다. TileLang의 타일 추상화와 프런트엔드, 하드웨어에 독립적인 변환 및 최적화를 그대로 활용합니다. 타일은 계산을 표현하는 데이터 블록입니다. 컴파일러는 온칩 메모리 할당, 데이터 전송, 연산 파이프라인 스케줄링, TPU 명령어 선택을 처리합니다. JIT(실행 시점 컴파일)를 통해 Python으로 정의한 커널을 장치에서 실행합니다. 개발자는 이러한 하드웨어 세부 사항을 직접 다루지 않고도 간결한 커널 코드를 작성할 수 있습니다. 평가한 워크로드에서는 제조사의 최적화된 구현과 같거나 더 나은 성능을 보였습니다.

현재 SOPHGO BM1690에서 딥러닝에 자주 쓰이는 연산을 지원하며, 해당 칩에서 성능 평가를 마쳤습니다. 실제 장치 실행과 소프트웨어 시뮬레이터를 이용한 디버깅을 모두 지원합니다. 앞으로는 대규모 언어 모델의 전체 추론 워크로드를 평가하고 여러 코어를 활용하도록 확장할 계획입니다.

TPU용 고성능 커널을 개발하려면 계산 내용뿐 아니라 온칩 메모리의 데이터 배치, 전송과 연산의 실행 순서, 하드웨어 명령어 인터페이스 호출도 정해야 합니다. TileLang-TPU는 TileLang의 Python 프런트엔드, 텐서 중간 표현(TIR), 공통 컴파일 패스를 재사용합니다. 하드웨어에 종속적인 작업은 TPU 전용 백엔드가 처리합니다.

개발자는 TileLang-TPU의 프런트엔드 연산으로 계산과 데이터 전송을 표현합니다. 현재 백엔드는 단일 코어 안에서 최적화하며, 코어 간 작업 분배는 아직 지원하지 않습니다. 입력 크기가 컴파일 시점에 정해지는 정적 형상만 지원하고, 동적 형상 컴파일은 지원하지 않습니다.

BM1690용 컴파일러 백엔드, JIT 런타임, 대규모 언어 모델에 자주 쓰이는 연산을 구현했습니다. 행렬 곱셈, RMSNorm, RoPE, SwiGLU, 원소별 덧셈, 리덕션 등을 지원하며, LLaMA와 DeepSeek 추론에 쓰이는 연산도 포함합니다.

성능은 SOPHGO BM1690 단일 코어에서 평가했습니다. TileLang-TPU와 SOPHGO Torch-TPU 연산 라이브러리에 포함된 제조사의 최적화된 PPL 구현을 같은 입력 형상과 데이터형으로 비교했습니다. 입력 형상은 컴파일 시점에 고정하며, 장치 측 커널 실행 시간을 측정했습니다. PPL(Primitive Programming Language)은 SOPHGO가 제공하는 커널 프로그래밍 언어입니다.

PPL 대비 평균 속도 향상은 행렬 곱셈 1.14×, RMSNorm 1.23×, RoPE 1.08×, SwiGLU 1.11×, 원소별 덧셈 1.05×입니다. 다섯 연산 종류 모두 평균 성능이 제조사 구현보다 높았습니다. 커널 구현 부분의 유효 코드 줄 수는 PPL보다 44.85% 줄었습니다. 평가한 워크로드에서는 타일 추상화로 더 간결한 코드를 작성하면서도 제조사 라이브러리와 같거나 더 나은 성능을 얻을 수 있었습니다.

여러 계산 단계를 하나로 합친 융합 커널도 지원합니다. 대규모 언어 모델의 핵심 어텐션 커널인 FlashAttention은 같은 알고리즘 표현을 사용했을 때 제조사의 PPL 구현 대비 평균 1.36×의 속도 향상을 보였습니다.

W8A16 역양자화 MLP 순방향 계산(MLP W8A16 Dequantized Forward)은 평가한 구성에서 PPL 대비 평균 1.01×로, 거의 같은 성능을 보였습니다. MLP는 모델의 순방향 신경망입니다. W8A16은 8비트 가중치와 16비트 활성값을 뜻하며, 역양자화는 저장된 저정밀도 가중치를 계산에 사용할 값으로 변환하는 과정입니다.

  • 다섯 입력 구성과 세 부동소수점 형식에서 다섯 연산 종류의 PPL 대비 속도 향상.
  • PPL 대비 FlashAttention과 W8A16 MLP의 평균 속도 향상은 각각 1.36×와 1.01×입니다.
  • 온칩 메모리 관리 TPU의 온칩 메모리 구조에 맞춘 자동 주소 할당 알고리즘을 구현했습니다. 컴파일러는 텐서의 형상, 데이터형, 읽기·쓰기 관계를 바탕으로 수명을 분석합니다. 수명이 겹치지 않는 텐서는 저장 공간을 공유하고, 동시에 읽는 텐서는 가능한 한 서로 다른 메모리 뱅크에 배치해 접근 충돌을 줄입니다.
  • 데이터 전송과 연산 파이프라이닝 컴파일러는 실행 유닛 간 데이터 의존성을 분석하고, 사용자가 지정한 파이프라인 단계 수에 맞춰 타일 루프의 데이터 로드, 연산, 저장을 배치합니다. GDMA 데이터 전송 유닛과 TIU 연산 유닛을 병렬로 실행하도록 스케줄링합니다. 현재 타일을 계산하는 동안 다음 타일을 준비해 전송과 연산을 세밀하게 중첩합니다.
  • 하드웨어 명령어 매핑 데이터 복사와 전송, 행렬 곱셈, 원소별 연산, 합계나 최댓값을 구하는 리덕션 등의 공통 연산을 TPU-Kernel 하드웨어 명령어 호출로 변환합니다. 컴파일러가 형상, 스트라이드, 주소, 데이터형을 채워 장치 코드를 생성합니다.
  • Python에서의 컴파일과 실행 JIT 컴파일은 장치 프로그램과 호스트 호출 코드를 자동으로 생성하고, 컴파일, 로딩, 커널 실행을 처리합니다. PCIe로 연결된 실제 TPU에서의 실행과 cmodel 소프트웨어 시뮬레이터를 이용한 디버깅을 지원합니다.

TileLang-RISC-V

프로젝트 책임자

AME 행렬 가속을 제공하는 RISC-V CPU에 TileLang을 이식합니다. 오픈소스 하드웨어·시스템 연구팀과 진행 중인 프로젝트입니다.

베이징 오픈소스 칩 연구원 및 중국과학원 소프트웨어연구소와 협력해 RISC-V AME AI CPU용 TileLang 백엔드를 개발하고 있습니다. 현재 프로그래밍 모델과 대상 명령어를 연결하고 실용적인 컴파일·실행 경로를 구축하는 데 집중합니다.

  • 대상 플랫폼 통합 컴파일 하향 변환, AME 명령어 매핑, 실행 환경을 연결합니다.
  • 평가 대상 구성별로 연산자의 정확성과 성능을 검증하고, 결과를 바탕으로 백엔드를 최적화합니다.
